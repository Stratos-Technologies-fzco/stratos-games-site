# 7. MATCH-3 GAME ENGINE

This is the most important development component.

Build a robust, independent Match-3 engine using TypeScript.

Board Configuration:

- Default board: 8 rows × 8 columns.
- Support configurable board dimensions.
- Support different board shapes.
- Support blocked cells.
- Support special cells.
- Support different crystal distributions.

Basic Crystals:

1. Ruby – Red.
2. Sapphire – Blue.
3. Emerald – Green.
4. Topaz – Yellow.
5. Amethyst – Purple.
6. Diamond – White.

Every crystal must have:

- Unique shape.
- Unique colour.
- Unique visual appearance.
- Selection state.
- Movement animation.
- Matching animation.
- Destruction animation.
- Special effects.

Gameplay Rules:

1. Players select a crystal.
2. Players swap adjacent crystals.
3. Only valid swaps are accepted.
4. Invalid swaps are automatically reversed.
5. Valid swaps consume one move.
6. Match three or more identical crystals.
7. Remove matched crystals.
8. Apply gravity.
9. Generate new crystals.
10. Detect cascading matches.
11. Process all cascades.
12. Update objectives and scores.
13. Check victory and failure.

Critical requirement:

Never allow a player to interact with the board while a previous move is being processed.

Use a proper game-state machine.

Suggested states:

- INITIALIZING.
- READY.
- SELECTING.
- SWAPPING.
- MATCHING.
- CLEARING.
- FALLING.
- REFILLING.
- CASCADING.
- CHECKING_OBJECTIVES.
- VICTORY.
- FAILURE.
- PAUSED.
