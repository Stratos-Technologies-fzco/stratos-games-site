One-paragraph studio description

Stratos Games is an indie mobile game studio co-founded by Sahil Modi and Shahariar Mody. They ship free casual, puzzle, word, and party games on Android, iOS, and the web. The studio’s production model pairs an AI build pipeline with a human play-test gate — every release is tested on a real device by a person before players see it. Currently shipping BLOXPLODE (block puzzle, on Google Play), Arrow Puzzle (logic puzzle, web), House Mafia (multiplayer social deduction, in development), and Word Quest (word search, in development).

The “humans test, AI builds, games ship” production model

Most studios fall into one of two patterns. They are either fast and unplayed (AI-coded games shipped raw, full of bugs nobody noticed because nobody played) or played and slow (hand-coded games where the play-test cycle is so expensive it kills cadence).

Stratos Games is built on the observation that the bottleneck in game development is not code — it is the play-test loop. AI generates code well; AI does not yet play games well. The studio puts AI on the production line and a human on the play-test gate, and gets the cadence of an AI-built studio with the quality of a hand-tested one.

In practice:

  • Shahariar plays every build on a real device. When something breaks or feels wrong, he files a structured build request describing the bug, the moment, and the device.
  • The AI build pipeline picks up each request, makes the smallest possible change, opens a pull request with the result, and routes it through automated quality checks.
  • A human reviews and merges every shipping change. No release reaches a player without that step.

The pipeline itself is open source. The factory repo is at https://github.com/sahilmodi1965/stratos-games-factory.
